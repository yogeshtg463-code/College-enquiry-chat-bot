PROJECT ADMINISTRATION

Maintain accurate student information

Chatbot answers are maintained in script.js. Update them only after confirming details from an official college or university source.

Technical note: This is a static GitHub Pages project. This page does not save changes to the live website or provide an authenticated administrator login.

Current knowledge-base coverage

  • BCA overview and general subject areas
  • BCA eligibility and duration guidance
  • BCA programming topics and career pathways
  • General course list from the original sample FAQ
  • Admissions, fees, timings, facilities, examinations and contact guidance

How to update an answer

  1. Open script.js in a code editor such as VS Code.
  2. Find the relevant item in the faqData array by its id.
  3. Update the keywords and answer fields using verified information.
  4. Save the file and test typical student questions in index.html.
  5. Commit and push the updated files to the GitHub repository to publish the changes.

Example FAQ structure

{
  id: "sample-topic",
  keywords: ["sample question", "another way to ask"],
  answer: "Insert the verified answer here."
}

Information still requiring official confirmation

The current verified-source set does not include the college's latest course prospectus, course-wise eligibility, semester syllabus, fee schedule, admission dates, office hours, official contact details or complete facilities list. These fields are deliberately not presented as confirmed facts.
